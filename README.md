# دفتر مالك

دفتر التسكات اليومي بتاع مالك: تسكات اليوم، والتسكات الفرعية، والعملاء، والبومودورو، والنوتس، ومتابعة الأسبوع.

- **الموقع:** https://malekahmed01.github.io/daftar-malek/
- **الكود:** ملف واحد `index.html` (HTML و CSS و JavaScript من غير مكتبات).
- **الداتا:** مش في الريبو ده. محفوظة في ريبو خاص (`daftar-malek-data`)، والصفحة بتوصله بمفتاح بيتحفظ في متصفح صاحب الدفتر بس. اللي يفتح الموقع من غير المفتاح بيلاقي دفتر فاضي.

## شكل الداتا

كل مجموعة ملف JSON في `data/` جوه ريبو الداتا: `tasks`، `notes`، `routine`، `clients`، `focus`، `settings`، `config`، و`projects` (قديمة). كل ملف عبارة عن `{"<id>": {...}}`.

## التعديل

أي تعديل على الكود بيتجرب الأول، وبيتسجل في سجل التعديلات، وبعدين يترفع هنا. GitHub Pages بينشر `index.html` من فرع `main` لوحده.
